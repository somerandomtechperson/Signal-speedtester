# Signal-speedtester

A lightweight, web-based tool designed to measure and analyze your local network and Wi-Fi connection performance.

## 🚀 Features
* **Real-time Metrics:** Accurately measures download speeds, upload speeds, and latency (ping).
* **Zero Installation:** Runs entirely in your browser using standard modern web technologies.
* **Tailored Interfaces:** Includes dedicated scripts for general Wi-Fi optimization (`wifi_speed_test.html`) and advanced signal testing (`signal_speed_test_v2.html`).

## 🛠️ Getting Started
Simply clone the repository and open either HTML file in any modern web browser to start testing your connection instantly.

Note: This project uses AI to assist in code and features. Don't worry, humans have inspected the code before it was uplaoded here, so you can be sure you are getting the right files and speed tester you need.
